A newspaper front page that sums up Friday 20 November 2026 world news in one image — Cyclone Akvan's landfall in India, Russian missiles over Kyiv, and Taiwan's stock crash, plus 34 more verified stories from every region. Rendered with Pillow and DejaVu fonts; every number and date is checked against manifest.json, and events from 18–19 November are confined to the Date Check box.

## Run it

```sh
python3 main.py
```

To regenerate the front page from the manifest, run `python3 build_image.py` first (requires Pillow; fonts are committed in `fonts/`).
